# 지수 데이터 출처

## Decisions

- 매매지수·전세지수는 한국부동산원(R-ONE) 주간 아파트가격동향을 단일 출처로 쓴다.

## Boundaries

- 이 결정은 시세 지수(구·시 단위 등락률)에만 적용된다. 개별 매물 시세·실거래가는 별도 출처를 쓸 수 있다.

## Why

R-ONE은 공식 통계이고 시·구 단위까지 API/파일로 제공되어 자동 수집이 가능하다. KB부동산 주간시세동향은 체감도는 높지만 공식 API가 없어 수집 방식이 더 까다롭다.

## Reconsider when

- R-ONE 데이터로 판단한 국면이 실제 체감과 반복적으로 어긋나는 경우, KB지수를 보조 지표로 추가하는 것을 재검토한다.

## Still-rejected alternatives

- KB부동산 주간시세동향 — 공식 API 부재로 수집 난이도가 높아 1순위에서 제외; R-ONE만으로 국면 판단 정확도가 부족하다고 판단되면 재검토.
