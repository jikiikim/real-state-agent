# 거래량 필터(월평균 5건)가 실제 데이터에서 거의 모든 아파트를 걸러낸다

**Symptom**: 원래 정의한 4개 필터 중 3번(3년 거래량 월평균 5건 이상)을 적용했더니, 서울 최상급지인 강남구에서도 아파트 514개 중 5개만 통과했다. 다른 조건(전세 상승률 32개, 매매〉전세 26개)은 훨씬 여유 있게 통과해서, 병목이 거래량 조건 하나였다.

**Observed evidence**: `lib/property-recommendation/aggregate.ts`의 `summarizeApartments` 결과를 직접 스크립트로 돌려 확인함(2026-08-27, 강남구 실거래가 실データ). 사용자에게 보고 후 "그 기준은 빼줘"로 확인받아 `rankTopApartments`에서 거래량 필터를 제거했다(`monthlyAvgTradeCount` 계산 자체는 유지해서 화면에 참고 정보로 보여준다).

**Suspected cause**: "거래량"을 아파트 하나의 전체 평형 거래 건수로 계산했는데, 개별 단지 단위로는 3년 월평균 5건(총 180건)이 매우 높은 기준이다. 강남구 전체 거래를 500개 넘는 단지가 나눠 갖다 보니 단지당 거래는 훨씬 적다.

**What was tried**: 조건을 그대로 적용 → Top 10이 거의 비어 필터를 제거함. 기준을 낮추는 대안(예: 월 1~2건)은 시도하지 않았다.

**Proposed next step**: 이 조건을 다시 넣고 싶다면, 지역 전체 단지의 거래량 분포를 보고 현실적인 임계치를 다시 잡거나(예: 상위 N% 또는 월 1건), "전체 평형"이 아니라 84㎡ 거래만으로 계산하는 방식도 비교해봐야 한다.
